Política de Privacidade

Extensão CallCenter - TOOLS para Google Chrome · Última atualização: 15 de outubro de 2026

Resumo

A extensão CallCenter - TOOLS foi feita para agilizar o trabalho de atendentes de call center. Ela não coleta, não envia e não compartilha dados pessoais. Todos os dados ficam armazenados localmente, no seu próprio navegador.

Dados que a extensão armazena

Tudo é salvo localmente no armazenamento do Chrome (chrome.storage.local), no seu computador:

  • Snippets (frases prontas) criados ou editados por você
  • Volume dos sons (áudios dos snippets e notificação de comando)
  • Som de confirmação personalizado (o arquivo de áudio que você escolher, guardado só neste navegador)
  • Posição dos botões da interface
  • Preferências de modo (botão flutuante / barra lateral) por site
  • Sites que você liberou para uso dos snippets
  • Lista de snippets padrão que você optou por ignorar
  • Configuração do botão PROX: instância, grupo escolhido e mensagem (padrão "prox"). A API Key do servidor de Zap já vem embutida no próprio pacote de instalação (arquivo local, fora do repositório público); se você usar "Alterar API Key", a chave digitada fica salva só neste navegador e é usada unicamente para autenticar no seu servidor

Esses dados nunca são enviados a servidores nossos ou de terceiros (a única exceção é a API Key, enviada ao seu próprio servidor de Zap). Apagar a extensão apaga todos eles.

Comunicações de rede

A extensão faz duas requisições de rede, ambas apenas quando você usa a função correspondente:

  • Lista padrão de snippets (um arquivo JSON de dados, sem código) do repositório público oficial github.com/Lucasmagista/EXTENSAO-CALL-CENTER, quando você clica em "Atualizar padrão" ou automaticamente a cada 60 minutos. Se o GitHub estiver indisponível, a cópia que vem embutida no pacote é usada.
  • Botão PROX: chamadas REST ao seu servidor Evolution em whatsapp.hubly.software (criar instância, gerar QR Code, listar seus grupos, enviar a mensagem escolhida e desconectar). Só essas ações, no momento em que você usar o botão; nenhum dado de terceiros é transmitido e nenhum código é baixado. A autenticação usa a API Key que vem no pacote de instalação.
  • Botão Sugestões: abre uma modal com o formulário (função, nome, email, setor, período e descrição) e usa as mesmas chamadas REST do PROX para entregar a mensagem padrão ao grupo de suporte no WhatsApp — só quando você clica em "Enviar sugestão". O email entra na mensagem apenas se você preencher (a mensagem deixa claro se ele foi adicionado ou não). Sem grupo configurado, o texto é copiado para a sua área de transferência, sem nenhuma requisição. O admin (senha dentro da própria modal) pode abrir a modal do suporte para conectar o WhatsApp da equipe e escolher esse grupo — mesma API Key, instância própria.

Não há telemetria, rastreamento, anúncios ou análise de comportamento.

Permissões e o que significam

  • Abas (tabs) e scripting: para inserir os botões e painéis da extensão nas páginas de atendimento que você usa (WhatsApp Web e Rocket.Chat).
  • activeTab: para agir na aba ativa somente quando você clica no ícone da extensão.
  • storage: para salvar localmente suas preferências e snippets.
  • offscreen: para reproduzir em segundo plano os áudios dos snippets, o som de confirmação tocado quando um comando é usado no chat e o som personalizado que você escolher.
  • alarms: para atualizar a lista padrão de snippets do GitHub a cada 60 minutos.
  • Permissões de site: restritas aos sites de atendimento; sites extras só são liberados mediante pedido e aceitação sua; acesso ao GitHub apenas para baixar a lista padrão de snippets; acesso ao seu servidor de Zap (whatsapp.hubly.software) apenas para as ações do botão PROX.

Menção a marcas de terceiros

Referências a produtos de terceiros (como aplicativos de mensagens ou plataformas de chat) são apenas descritivas do funcionamento da extensão e não indicam patrocínio, afiliação ou endosso por parte dessas empresas.

Crianças

A extensão é uma ferramenta profissional de trabalho e não é destinada a crianças.

Alterações nesta política

Qualquer mudança será publicada nesta mesma página, com a data da última atualização ajustada.
