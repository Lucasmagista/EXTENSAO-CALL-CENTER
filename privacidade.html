Política de Privacidade

Extensão CallCenter - TOOLS para Google Chrome · Última atualização: 16 de outubro de 2026

Resumo

A extensão CallCenter - TOOLS foi feita para agilizar o trabalho de atendentes de call center. Ela não coleta nem envia dados a servidores nossos — não há telemetria nem rastreamento. Seus dados ficam armazenados localmente, no seu próprio navegador. As duas únicas coisas que podem sair do seu computador são: conteúdo que você mesmo digita no formulário de Sugestões (entregue ao grupo de suporte no WhatsApp só quando você clica em "Enviar sugestão") e as chamadas ao seu servidor de Zap quando você usa o botão PROX.

Dados que a extensão armazena

Tudo é salvo localmente no armazenamento do Chrome (chrome.storage.local), no seu computador:

  • Snippets (frases prontas) criados ou editados por você
  • Volume dos sons (áudios dos snippets e notificação de comando)
  • Som de confirmação personalizado (o arquivo de áudio que você escolher, guardado só neste navegador)
  • Posição dos botões da interface
  • Preferências de modo (botão flutuante / barra lateral) por site
  • Sites que você liberou para uso dos snippets (somente sites HTTPS)
  • Lista de snippets padrão que você optou por ignorar
  • Configuração do botão PROX: instância, grupo escolhido e mensagem (padrão "prox"). A API Key vem embutida no arquivo local da instalação (assets/prox-servidor.json, fora do git) ou é digitada por você em "Alterar API Key" — no segundo caso ela fica salva só neste navegador; em qualquer caso é usada unicamente para autenticar no seu servidor. Dois registros técnicos da área do admin também ficam locais: o bloqueio após tentativas erradas de senha e o token temporário liberado pela senha certa (a senha em si não é gravada)
  • Configuração de suporte baixada do repositório (grupo de destino das sugestões, quando o admin publica)

Esses dados nunca são enviados a servidores nossos ou de terceiros não relacionados. As exceções são: a API Key (vinda do pacote ou digitada) e as chamadas do PROX vão ao seu próprio servidor de Zap; o texto do formulário de Sugestões vai ao grupo de suporte no WhatsApp (pelo seu servidor, só quando você clica em enviar); e a extensão baixa dados do repositório oficial (lista de snippets e, se publicada, a config de suporte). Apagar a extensão apaga todos os dados locais.

Comunicações de rede

A extensão faz três tipos de requisições de rede, ambas apenas quando você usa a função correspondente (ou, no caso das duas primeiras, automaticamente a cada 60 minutos):

  • Lista padrão de snippets (um arquivo JSON de dados, sem código) do repositório oficial github.com/Lucasmagista/EXTENSAO-CALL-CENTER, quando você clica em "Atualizar padrão" ou automaticamente a cada 60 minutos. Se o GitHub estiver indisponível, a cópia que vem embutida no pacote é usada.
  • Configuração de suporte (também JSON de dados, sem código e sem chave): o arquivo assets/suporte-config.json do mesmo repositório, com o grupo de destino das sugestões e o identificador da instância do suporte (sem credencial) escolhidos pelo admin — baixado na mesma janela de 60 minutos, com fallback para a cópia embutida. Ele só existe para o time inteiro receber a mesma configuração; não contém dados pessoais nem credenciais.
  • Botão PROX: chamadas REST ao seu servidor Evolution em whatsapp.hubly.software (criar instância, gerar QR Code, listar seus grupos, enviar a mensagem escolhida e desconectar). Só essas ações, no momento em que você usar o botão; nenhum dado de terceiros é transmitido e nenhum código é baixado. A autenticação usa a API Key vinda do arquivo local do pacote (fora do git) ou digitada por você em "Alterar API Key".
  • Botão Sugestões: abre uma modal com o formulário (função, nome, email, setor, período e descrição) e usa as mesmas chamadas REST do PROX para entregar a mensagem padrão ao grupo de suporte no WhatsApp — só quando você clica em "Enviar sugestão". O que você escreve (inclusive o email, só se preenchido) vai para esse grupo de trabalho; a mensagem deixa claro se o email foi adicionado ou não. Sem grupo configurado, o texto é copiado para a sua área de transferência, sem nenhuma requisição. O admin (senha verificada dentro da própria extensão, nunca em código) pode abrir a modal do suporte para conectar o WhatsApp da equipe e escolher esse grupo — mesma API Key, instância própria.

Não há telemetria, rastreamento, anúncios ou análise de comportamento.

Permissões e o que significam

  • Abas (tabs) e scripting: para inserir os botões e painéis da extensão nas páginas de atendimento que você usa (WhatsApp Web e Rocket.Chat).
  • activeTab: para agir na aba ativa somente quando você clica no ícone da extensão.
  • storage: para salvar localmente suas preferências e snippets.
  • offscreen: para reproduzir em segundo plano os áudios dos snippets, o som de confirmação tocado quando um comando é usado no chat e o som personalizado que você escolher.
  • alarms: para atualizar a lista padrão de snippets do GitHub a cada 60 minutos.
  • Permissões de site: restritas aos sites de atendimento (todos HTTPS); sites extras só são liberados mediante pedido e aceitação sua, apenas endereços HTTPS (o Chrome não oferece mais permissão de site sem criptografia nesta extensão); acesso ao GitHub apenas para baixar dados JSON (lista padrão de snippets e configuração de suporte); acesso ao seu servidor de Zap (whatsapp.hubly.software) apenas para as ações do botão PROX.

Menção a marcas de terceiros

Referências a produtos de terceiros (como aplicativos de mensagens ou plataformas de chat) são apenas descritivas do funcionamento da extensão e não indicam patrocínio, afiliação ou endosso por parte dessas empresas.

Crianças

A extensão é uma ferramenta profissional de trabalho e não é destinada a crianças.

Alterações nesta política

Qualquer mudança será publicada nesta mesma página, com a data da última atualização ajustada.
